# Objectif
Créer une application de suivi de l'alimentation et de l'activité

# Fonctionnalité
L'application doit utiliser des API open source pour déterminer les macro nutritionnel du produit à partir d'un code barre

# Stack technique
- Interface WEB en shadcn/ui en React / Typescript
- Serveur Back API en NestJS / Typescript
- Base NoSQL MongoDB pour la persistence

  L'interface est basé sur la skill /ui-ux-pro-max et /ckm:ui-styling

Le déploiement se fera sur un compte Vercel gratuit
